# C++20 TUI RSS / Atom Reader

Консольная RSS/Atom-читалка с интерактивным интерфейсом на базе библиотеки **FTXUI**, сетевым слоем на **libcurl** и архитектурой, разделенной на изолированные слои. Проект разработан в рамках выполнения задания по C++20.

---

## Основные возможности

- **Интерактивный TUI-интерфейс**: Полноценное управление клавиатурой (навигация стрелками, просмотр статей, скролл, удобные подсказки внизу экрана).
- **Поддержка стандартов RSS 2.0 и Atom**: Автоматическое определение формата ленты через паттерн «Фабрика» (Factory).
- **Сетевой клиент с кэшированием**: Загрузка лент по сети с поддержкой HTTP-заголовков `ETag` и `Last-Modified` (статус `304 Not Modified`), что экономит трафик и ускоряет обновление.
- **Персистентность (сохранение состояния)**:
  - Автоматическое сохранение добавленных подписок в файл `feeds.txt`.
  - Сохранение статуса прочитанных статей в файл `read_articles.txt`.
- **Индикатор прочитанных статей**: Прочитанные статьи визуально выделяются тусклым цветом (`| dim`) без лишних громоздких символов.
- **Интерактивный поиск**: Фильтрация статей по названию в реальном времени (клавиша `/`).
- **Открытие ссылок в браузере**: Возможность открывать сноски/ссылки из статей с помощью цифровых клавиш (`1-9`).
- **Строгие стандарты компиляции**: Проект компиллируется с флагами `-Wall -Wextra -Werror` без единого предупреждения.

---

## Архитектура проекта

Проект построен по принципам модульности и разделения ответственности (3-ярусная архитектура):
1. **Core (Ядро)**: Модели данных (`Article`, `Feed`), парсеры XML (RSS/Atom), рендерер HTML-контента статей. Полностью независим от сетевого слоя и UI.
2. **Network (Сеть)**: Обертка над `libcurl` (`HttpClient`), управляющая HTTP-запросами и заголовками кэширования.
3. **App (Слой приложения)**: Менеджер подписок (`FeedManager`), управляющий коллекцией лент, потокобезопасностью и состоянием.
4. **TUI (Интерфейс)**: Экранные компоненты и обработчики событий на базе библиотеки `FTXUI`.

## Требования для сборки

Для сборки проекта вам понадобятся:
- Компилятор с полной поддержкой **C++20** (например, `g++` версии 10+ или `clang++`).
- Система сборки **CMake** (версия 3.15 или выше).
- Библиотека **libcurl** (для сетевых запросов).
- Зависимости `FTXUI` и `doctest` .

## Сборка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <ссылка-на-репозиторий>
   cd rss-reader```
   
2. Создайте директорию сборки и сгенерируйте файлы Make:

    ```cmake -B build -S .```

3. Соберите проект:

    ```cmake --build build -j4```

4. Запустите приложение

    ```./build/rss_tui```


## Управление в программе

### Экран списка лент (FeedsList)

- Up/Down - Скролл.
- Enter - Открыть выбранную ленту со списком статей.
- a - Добавить новую ленту по URL.
- d - Удалить выбранную ленту подписки.
- q - Выход из программы.

### Экран списка статей (ArticlesList)

- Up/Down - Скролл.
- Enter - Открыть выбранную статью.
- / - Поиск статей по нзванию.
- Esc - Вернуться к списку лент.
- q - Выход из программы

### экран просмотра статьи (ArticleView)

- Up/Down - Скролл.
- 1-9 - Открыть соответствующую ссылку из статьи в системном браузере.
- Esc - Вернуться к списку статей.
- q - Выход из программы.
